## 2026-09-04 - Caching file reads in Python dashboard scripts
**Learning:** Python dashboard scripts that aggregate data across many markdown files ("chunks") can easily introduce N+1 or redundant I/O patterns. For example, counting words for token savings and then re-counting the same files to generate a timeline chart. Even for small numbers of files, avoiding duplicate disk reads by caching results (e.g., in a dictionary) provides a measurable structural performance improvement and reduces execution overhead.
**Action:** When working on scripts that iterate over directories of files to calculate metrics, always analyze the entire script to identify if the same files are processed multiple times. Cache the results of expensive operations (like `open().read()` or derived aggregations) on the first pass to eliminate redundant I/O operations in subsequent steps.
