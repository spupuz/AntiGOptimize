## 2024-08-23 - Batching external process calls in Bash loops (N+1 Anti-Pattern)
**Learning:** Calling external processes like `jq` or `wc` inside loops in Bash scripts introduces significant N+1 process spawning overhead. For example, fetching three values from the same JSON file using three separate `jq` commands is much slower than executing `jq` once and using process substitution. Similarly, calling `wc -w` on individual files inside a loop is inefficient compared to streaming all files into a single `wc -w` command. Additionally, naive globbing like `cat dir/*.md` can fail with "Argument list too long" or hang indefinitely on empty directories if `nullglob` is enabled.
**Action:** When extracting multiple values from a JSON file in a bash script, always batch the extraction into a single `jq` execution (e.g., using `@tsv` output and reading into variables via process substitution). When performing file I/O operations like word counting across multiple files, use robust batching with `find dir -name "*.md" -type f -print0 | xargs -r -0 cat | wc -w` instead of calling the subprocess inside a loop or relying on unsafe naive globbing.
