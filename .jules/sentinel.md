## 2026-08-18 - Critical Command Injection in Python Scripts Embedded in Shell
**Vulnerability:** Shell variables (`$PROJECT_NAME`, `$TASKS_HISTORY`, etc.) were directly interpolated into strings representing Python scripts run via `python3 -c "..."`. This allowed an attacker to execute arbitrary Python code by injecting single quotes and Python payloads into variable values (e.g. project names or filenames).
**Learning:** Even though the scripts are invoked from a bash environment, dynamically constructing code strings in interpreted languages (Python, Node.js) using bash parameter expansion is a direct vector for command injection.
**Prevention:** Never use string interpolation to pass dynamic data into embedded scripts. For Python, pass dynamic strings securely via `sys.argv` (e.g. `python3 -c "import sys; print(sys.argv[1])" "$VAR"`) or standard environment variables (`os.environ`). For JSON escaping specifically, utilities like `jq --arg` provide a robust alternative.

## 2026-08-25 - XSS Vulnerability in JSON Data Generation Scripts
**Vulnerability:** The data generation scripts (`dist/scripts/collect-dashboard-data.py` and `dist/scripts/collect-dashboard-data.sh`) serialized project data into JSON format without escaping the `<` character. If malicious or unexpected `<script>` tags were present in project files (e.g. `project-summary.md`), this JSON output, when directly embedded in `<script>` tags in `dashboard.html` as the `{{DATA}}` placeholder, would lead to Cross-Site Scripting (XSS).
**Learning:** Even if data is strictly formatted as JSON, if it is destined to be embedded inside a `<script>` tag in an HTML document, the browser's HTML parser runs before the JS engine. An unescaped `</script>` inside a JSON string literal will terminate the script block and allow execution of subsequent HTML injected by the attacker.
**Prevention:** Always escape the `<` character as `\u003c` in any JSON payload that is intended for inline injection into HTML templates, regardless of the perceived safety of the input data.
