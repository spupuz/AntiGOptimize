## 2024-05-23 - Prevent Symlink Traversal and Ensure Atomicity in Shell Scripts
**Vulnerability:** Shell scripts using direct output redirection (`>`) or predictable temporary file names (e.g., `file.tmp`) are vulnerable to symlink traversal attacks and race conditions. This can allow attackers to overwrite arbitrary files or lead to data corruption when scripts are executed concurrently.
**Learning:** Security mechanisms often inadvertently introduce functional regressions. In this case, `mktemp` creates temporary files with restrictive `0600` permissions. Without explicitly resetting permissions, moving these files into place can result in unreadable configuration or script files. Furthermore, temporary files must be created on the same filesystem as the destination to guarantee that the `mv` command performs an atomic rename (`rename(2)`) rather than a slow, non-atomic copy-and-delete operation.
**Prevention:** Always use `mktemp` to generate unpredictable temporary files, creating them in the target directory (e.g., `mktemp "$(dirname "$target")/.tmp.XXXXXX"`). Explicitly apply `chmod 644` to the temporary file to restore standard readable permissions before securely replacing the destination file with `mv`.
