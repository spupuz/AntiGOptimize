## 2024-05-24 - Visual Progress Bar Accessibility
**Learning:** Visual progress bars implemented with `div` elements are entirely opaque to screen readers unless explicitly marked up. The wrapper element must receive the `role="progressbar"` attribute along with `aria-valuemin` and `aria-valuemax`. More crucially, the `aria-valuenow` attribute must be updated dynamically via JavaScript alongside the visual width to ensure users relying on assistive technologies receive real-time status updates during long-running tasks.
**Action:** When implementing visual progress bars (e.g., using filled div elements), always attach ARIA progressbar attributes (`role="progressbar"`, `aria-valuemin`, `aria-valuemax`) to the wrapper container and dynamically sync `aria-valuenow` via JavaScript to maintain screen reader accessibility.
